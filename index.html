Como criar a chave
  1. Acesse console.cloud.google.com e crie um projeto.
  2. Em “APIs e serviços”, ative a YouTube Data API v3.
  3. Em “Credenciais”, escolha “Criar credenciais” e depois “Chave de API”.
  4. Restrinja a chave à YouTube Data API v3 e ao endereço do seu site.

A chave de IA não é salva no navegador. Em produção, ela fica só no servidor.

Qualquer visitante da página pode copiar uma chave colocada nela. Por isso, restrinja a chave do YouTube ao seu site e nunca deixe chaves de IA no navegador.

Protótipo de interface. Os resultados do canal são exemplos simulados a partir do @ digitado. A análise real exige conectar a API do YouTube e um modelo de IA em um servidor. As cores das thumbnails são calculadas de verdade, no seu navegador.
